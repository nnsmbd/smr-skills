# Content Mode

Use `content` for site articles and organic social content. First establish the central promise, source material, intended reader effect, canonical source status, and target channel.

## Choose the content job

- `build-in-public`: result → real process detail → limitation → current state → next step;
- `reflection`: realization → situation → provisional framework → next action;
- `explainer`: useful promise → plain-language translation → method or system → constraints;
- `case-study`: concrete hook → why it existed → what it became → how it works → role of AI or tools → limitations → lessons;
- `roadmap`: what changes → what stays → grouped directions → expected reader value;
- `weekly-log`: period or mood → concrete work/life points → next action;
- `digest`: verified scope → ranked topics → attributed evidence → Samir's synthesis.

Treat these as candidate structures, not mandatory templates. Build the scenario from the asset's promise before selecting source details.

## Separate content from its distribution

The same idea can have one canonical site article and several social variants. Track them under one `content_id`. Distinguish:

- `verbatim`: same copy with formatting-only changes;
- `adapted`: the argument is rebuilt for a channel;
- `teaser`: one useful part is published with an optional link to the canonical source.

Do not treat publication on several channels as several independent proofs of a voice pattern.

## Evidence rule

Confirmed information does not automatically belong in the asset. Include a fact only when it advances the central promise, reader understanding, trust, or intended action.

For personal content, do not invent a lived scene. For technical content, use technical details to explain the product or decision rather than demonstrate how much repository material was inspected.

## Ending

Use the smallest ending that fits: a next experiment, feedback request, specific question, useful link, or compact conclusion. Do not attach a generic engagement question or commercial pitch to every piece.
