# Telegram

Evidence status: strong. The supplied Telegram corpus is the primary evidence for the current shared voice.

## Shape

- Use generous mobile whitespace and short paragraphs.
- Start with the shipped thing, honest problem, surprising detail, realization, or blunt translation.
- Use lists when Samir is organizing a system, features, themes, or weekly observations.
- State limitations early in build-in-public posts.
- Let one restrained aside or self-ironic detail humanize the post; do not schedule humor by quota.

## Typical structures

- `result → human process detail → limitation → what exists → what comes next → feedback`;
- `realization → context → small framework → next action`;
- `complex name → plain-language translation → personal setup by points`;
- `verified discussion → grouped topics → От себя` for digests.

## Avoid

- repeating the title as the first sentence;
- excessive emoji or bold used to rescue weak content;
- turning every observation into a universal lesson;
- converting an organic post into hidden sales copy.
