# Threads

Evidence status: provisional; no approved Threads corpus is stored yet.

## Default adaptation

- Use one observation per post or one connected line of thought per thread.
- Open with the actual claim or incident, not `тред о том, как...`.
- Let replies extend the argument rather than repeat the opening.
- Keep conversational incompleteness only when meaning remains clear.
- Do not manufacture controversy, bait questions, or fake certainty for replies.

Do not record these platform defaults as Samir-specific voice cues until user-edited examples exist.
